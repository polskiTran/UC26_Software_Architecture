# Software Architecture Assignment 4 - 3LayerArch

- Original repo - [3LayerArch](https://github.com/lunarlunarll123/3LayerArch)
- Assignment [link](https://uc.instructure.com/courses/1830312/assignments/23190164)

## How to run
### Option 1 - `requirements.txt`
```bash
# Install dependecies
cd assignment4/
pip install -r requirements.txt

# Run the proj
python main.py
```

### Option 2 - `uv`
- Make sure [uv](https://docs.astral.sh/uv/) is installed
```bash
# Install dependecies
cd assignment4/
uv sync

# Run the proj
uv run main.py
```
